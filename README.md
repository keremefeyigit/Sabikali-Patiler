# 🐾 Sabıkalı Patiler

[![HTML5](https://img.shields.io/badge/HTML5-Modern-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-Vanilla-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Saf HTML, CSS ve JavaScript kullanılarak geliştirilmiş, akıcı kullanıcı arayüzüne ve eğlenceli dinamiklere sahip web tabanlı interaktif oyun projesi.

---

## 🌟 Özellikler

- **Saf Vanilla Mimarisi:** Dış bağımlılık veya ağır kütüphaneler olmadan yüksek performanslı çalışma.
- **Responsive Tasarım:** Tüm ekran boyutlarıyla uyumlu dinamik arayüz.
- **Akıcı Animasyonlar:** CSS3 geçişleri ve JavaScript olay yönetimi ile eğlenceli kullanıcı deneyimi.

---

## 🛠️ Teknolojiler

- **HTML5:** Yapısal içerik ve semantik etiketler.
- **CSS3:** Özel CSS değişkenleri, Flexbox & Grid mimarisi.
- **JavaScript:** Olay dinleyicileri (Event Listeners) ve oyun mantığı.

---

## 💻 Nasıl Çalıştırılır?

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/keremefeyigit/sabikali-patiler.git
   ```
2. `index.html` dosyasını çift tıklayarak tarayıcınızda açın.
